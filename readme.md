## SoloRush_Luffythèque

---

# Intitulé du projet

- Mini projet full stack sur le thème de One Piece: **"Luffythèque"**

Une page web qui affiche une carte pour chaque forme (évolution) de Luffy. En cliquant sur une carte, on découvre ce que fait cette forme et ses attaques.

# Technologies

- VSCode, Git, GitHub, excalidraw, googleSheets, trello, canva
- Front-end: React, vite, nodejs, css, typeScript, react-router
- Back-end: Nodejs, express, postgreSQL, SQLelectron, Bruno

---

# Fonctionnalités

- Affichage d'une carte par forme de Luffy.
- Au clic sur une carte : description de la forme et liste de ses attaques.
